Naver SMTP 설정

Python 이메일 자동화를 위해 네이버 계정의 SMTP 발송 기능을 활성화하는 방법을 안내합니다.

SMTP 서버 smtp.naver.com 네이버 메일 발송 서버
포트 587 TLS 암호화 연결
인증 방식 STARTTLS server.starttls()
계정 네이버 ID @naver.com 아이디 + 비밀번호
1

네이버 메일 설정 — SMTP 발송 허용

네이버 메일 웹사이트에서 환경설정 → POP3/IMAP 설정 메뉴를 열고 SMTP 사용함을 선택한 뒤 저장합니다. 이 설정이 활성화되어야 Python에서 네이버 계정으로 메일을 발송할 수 있습니다.

주의 2단계 인증이 활성화된 계정은 앱 비밀번호를 별도로 발급받아 사용해야 합니다. 네이버 보안 설정 → 2단계 인증 관리 → 앱 비밀번호 발급에서 생성할 수 있습니다.
2

외부 접속 허용 확인

POP3/SMTP 사용함으로 설정한 후 저장 버튼을 클릭합니다. 외부 메일 클라이언트나 Python 스크립트에서 이 계정으로 연결할 수 있는지 확인하는 화면입니다.

참고 설정 완료 후 Python 코드에서 smtplib.SMTP("smtp.naver.com", 587)로 연결하면 정상적으로 메일을 발송할 수 있습니다.
