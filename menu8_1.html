OpenAI API Key 생성
  • 1
    OpenAI Platform 접속 platform.openai.com 으로 이동합니다.
  • 2
    로그인 이메일 계정 또는 Google / Microsoft 계정으로 로그인합니다. 계정이 없다면 Sign up으로 신규 가입합니다. 신규 가입 시 전화번호 인증이 필요할 수 있습니다.
  • 3
    API keys 페이지 이동 좌측 사이드바에서 사용할 프로젝트를 선택한 뒤 API keys 메뉴를 클릭합니다.
  • 4
    새 키 생성 우측 상단의 Create new secret key 버튼을 클릭합니다. 팝업 창에서 키 이름을 입력하고 권한을 선택합니다. 권한: All (전체) 또는 Restricted (기능별 세부 설정)
  • 5
    키 복사 및 저장 Create secret key를 클릭하면 키가 생성됩니다. 화면에 표시된 키를 즉시 복사하여 안전한 곳에 보관하세요. ⚠ 창을 닫으면 키를 다시 확인할 수 없습니다.
