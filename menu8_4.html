role 이해하기

role 이란?

OpenAI API에 메시지를 보낼 때 각 메시지가 누구의 말인지를 지정하는 것이 role입니다.
역할을 구분해야 모델이 대화의 맥락을 올바르게 이해할 수 있습니다.

developer

개발자 지시 (구버전: system)

모델이 어떻게 동작할지 규칙과 역할을 정해줍니다. 대화가 시작되기 전에 한 번 설정합니다.
최신 API에서는 system 대신 developer를 사용합니다.

예: "당신은 친절한 고객센터 상담원입니다. 반말을 사용하지 마세요."
user

사용자 입력

실제로 모델에게 질문하거나 요청하는 내용입니다. 사람이 입력하는 메시지입니다.

예: "배송이 3일 늦어졌다는 고객 문의에 답변해줘."
assistant

모델의 답변

모델이 생성한 응답입니다. 대화를 이어갈 때 이전 답변을 함께 전달하면 맥락을 유지할 수 있습니다.

예: "안녕하세요, 배송 지연으로 불편을 드려 죄송합니다..."
system → developer 변경 이유
기존 system은 역할이 모호했습니다. developer로 바꿔 "이 지시는 개발자가 설정한 것"임을 명확히 했습니다. 이전 코드에서 system을 사용해도 계속 동작하지만, 새 프로젝트에서는 developer를 사용하는 것을 권장합니다.
Chat Completions API vs Responses API — role 비교

두 API 모두 같은 개념을 사용하지만 코드 구조가 다릅니다.

Chat Completions API

모든 지시와 대화를 messages 배열 하나에 넣습니다.

Responses API

개발자 지시는 instructions로 분리하고, 대화만 input에 넣습니다.

Chat Completions API — developer role 사용 예시

from openai import OpenAI
client = OpenAI()

completion = client.chat.completions.create(
    model="gpt-6-luna",
    messages=[
        {"role": "developer", "content": "당신은 친절한 고객센터 상담원입니다."},
        {"role": "user",      "content": "배송이 3일 늦어졌다는 고객 문의에 답변해줘."},
    ]
)
print(completion.choices[0].message.content)

Responses API — instructions + user 사용 예시

instructions

개발자 지시 (Responses API 전용)

Chat Completions의 developer 역할과 동일한 개념입니다.
별도 파라미터로 분리되어 코드가 더 명확해집니다.

response = client.responses.create(
    model="gpt-6-luna",
    instructions="당신은 친절한 고객센터 상담원입니다.",  # developer role 역할
    input=[
        {"role": "user", "content": "배송이 3일 늦어졌다는 고객 문의에 답변해줘."}
    ]
)
print(response.output_text)
