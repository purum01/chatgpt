LangChain으로 ChatGPT 사용하기
LangChain의 핵심 구성 요소인 ChatOpenAI, PromptTemplate, ChatPromptTemplate, Chain 패턴을 단계적으로 학습합니다.
① LangChain이란?

LangChain은 LLM(대형 언어 모델) 기반 애플리케이션 개발을 위한 프레임워크입니다.

OpenAI API를 직접 사용하는 것보다 훨씬 적은 코드로 복잡한 기능을 구현할 수 있습니다.

주요 특징

  • PDF, 웹사이트, YouTube 등 외부 데이터를 LLM과 연결하기 쉬움
  • 프롬프트를 재사용 가능한 템플릿으로 관리
  • 파이프라인(Chain) 방식으로 여러 기능을 조합
  • 다양한 LLM (OpenAI, Gemini, Claude 등) 교체 가능

설치

pip install langchain
pip install langchain-openai
② ChatOpenAI — LangChain에서 GPT 사용하기

ChatOpenAI는 LangChain에서 OpenAI의 GPT 모델을 사용할 때 쓰는 클래스입니다.

환경변수 OPENAI_API_KEY가 설정되어 있으면 api_key를 별도로 전달하지 않아도 됩니다.

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-6-luna")

messages = [
    ("system", "You are a helpful assistant that translates English to Korean."),
    ("human", "Translate this sentence from English to Korean. I love programming."),
]

response = llm.invoke(messages)
print(response.content)   # 저는 프로그래밍을 좋아해요.

OpenAI API vs LangChain 역할 비교

LangChain OpenAI API 의미
"system" "system" AI의 역할, 규칙, 지침 설정
"human" "user" 사용자가 입력한 메시지
"ai" "assistant" AI가 응답한 메시지
③ PromptTemplate — 재사용 가능한 프롬프트 만들기

PromptTemplate은 프롬프트를 변수가 있는 템플릿으로 정의해서 재사용할 수 있게 해줍니다.

{변수명} 형태로 변수를 삽입하고 .format()으로 값을 채웁니다.

from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate(
    template="""
다음 문장을 {language}로 번역하세요.

문장: {text}
""",
    input_variables=["language", "text"],
)

# 변수에 값을 채워 프롬프트 생성
prompt_text = prompt.format(
    language="영어",
    text="인공지능은 우리의 업무 방식을 변화시키고 있습니다."
)

print(prompt_text)

# LLM에 전달
response = llm.invoke(prompt_text)
print(response.content)
💡 핵심 포인트
언어나 텍스트만 바꾸면 동일한 템플릿을 계속 재사용할 수 있습니다.
코드에 프롬프트를 하드코딩하는 것보다 유지보수가 훨씬 쉬워집니다.
④ ChatPromptTemplate — 역할별로 프롬프트 구조화하기

ChatPromptTemplate은 PromptTemplate의 발전형으로, 프롬프트를 system / human / ai 역할별 메시지로 구조화할 수 있습니다.

from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "You are a helpful assistant that translates {input_language} to {output_language}."),
        ("human", "{input}")
    ]
)

# 변수에 값 채우기
filled = prompt.format_messages(
    input_language="English",
    output_language="Korean",
    input="I love programming."
)

print(filled)

PromptTemplate vs ChatPromptTemplate 비교

PromptTemplate ChatPromptTemplate
형태 단순 문자열 역할별 메시지 목록
system 지정 불편함 편리함
Chain 연결 가능 권장
⑤ Chain — prompt | llm 파이프라인 패턴

LangChain의 가장 강력한 특징은 | 연산자로 컴포넌트를 파이프라인처럼 연결하는 것입니다.

프롬프트 → LLM → 출력 파서 순서로 데이터가 흘러갑니다.

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(model="gpt-6-luna")

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant that translates {input_language} to {output_language}."),
    ("human", "{input}")
])

# 파이프라인 연결: 프롬프트 → LLM → 문자열 파서
chain = prompt | llm | StrOutputParser()

# 실행
result = chain.invoke({
    "input_language": "English",
    "output_language": "Korean",
    "input": "I love programming.",
})

print(result)   # 저는 프로그래밍을 좋아해요.
💡 StrOutputParser를 추가하는 이유
prompt | llm만 쓰면 결과가 AIMessage(content='...') 객체로 반환됩니다.
StrOutputParser()를 추가하면 문자열만 깔끔하게 추출됩니다.

언어만 바꿔서 재사용하기

# 한국어 → 영어
print(chain.invoke({
    "input_language": "Korean",
    "output_language": "English",
    "input": "나는 프로그래밍을 좋아합니다.",
}))

# 일본어 → 한국어
print(chain.invoke({
    "input_language": "Japanese",
    "output_language": "Korean",
    "input": "私はプログラミングが好きです。",
}))
💡 Chain의 핵심 장점
입력 변수만 바꾸면 동일한 파이프라인을 반복 재사용할 수 있습니다.
나중에 LLM을 다른 모델로 교체하거나 중간에 단계를 추가하기도 쉽습니다.
⑥ 전체 학습 내용 정리
구성 요소 역할 핵심 메서드
ChatOpenAI GPT 모델 연결 .invoke()
PromptTemplate 단순 문자열 템플릿 .format()
ChatPromptTemplate 역할별 메시지 템플릿 .from_messages()
StrOutputParser AIMessage → 문자열 변환 Chain 끝에 연결
prompt | llm 파이프라인 연결 .invoke()
🔗 학습 흐름
ChatOpenAI 직접 사용 → PromptTemplate으로 재사용성 확보 → ChatPromptTemplate으로 역할 구조화 → Chain (|)으로 파이프라인 완성
