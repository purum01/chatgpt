개발 환경 구축하기

업무 자동화를 위한 Python 개발 환경을 단계별로 설치합니다.

1

수업 파일 다운로드

파일 다운로드
2

파이썬 설치 (Anaconda)

anaconda.org 이동
3

VSCode 설치

code.visualstudio.com 이동
4

가상환경 구축

① 가상환경 생성하기

python -m venv myenv

② 가상환경 실행하기

.\myenv\Scripts\activate

③ 가상환경 종료하기

deactivate
5

파이썬 라이브러리 설치

pip install -r requirements.txt
