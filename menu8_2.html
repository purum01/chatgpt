STEP 2  Chat Completions API 기본

Chat Completions API 참조 : 공식 문서

from openai import OpenAI

client = OpenAI()

messages의 role 종류

  • developer  —  개발자가 모델에게 주는 지침/규칙 (개발자의 지시)
  • user  —  사용자가 입력한 내용 (사용자 질문)
  • assistant  —  모델이 생성한 답변 (AI 이전 답변)
completion = client.chat.completions.create(
    model="gpt-6-luna",
    messages=[
        {"role": "developer", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

비용 계산 함수

def calculate_cost(completion, exchange_rate=1400):
    # 토큰 사용량
    input_tokens  = completion.usage.prompt_tokens
    output_tokens = completion.usage.completion_tokens

    # USD 비용 계산
    input_cost  = input_tokens  * 0.10 / 1_000_000
    output_cost = output_tokens * 0.50 / 1_000_000
    total_usd = input_cost + output_cost

    # KRW 비용 계산
    total_krw = total_usd * exchange_rate

    return total_usd, total_krw

calculate_cost(completion)
STEP 4  run_chat 함수 
def run_chat(messages):
    completion = client.chat.completions.create(
        model="gpt-6-luna",
        messages=messages
    )
    # 답변 출력
    print(completion.choices[0].message.content)

    # 비용 계산 및 출력
    usd, krw = calculate_cost(completion)
    print(f"비용: ${usd:.6f} / {krw:.2f}원")

STEP 8  Responses API
Responses API란?
OpenAI가 2025년 3월에 출시한 새로운 방식의 API입니다.
앞서 배운 Chat Completions API가 없어지는 것이 아니라, 새로운 프로젝트에는 Responses API를 사용하도록 권장하고 있습니다.

Chat Completions API와 무엇이 다를까?

핵심 개념은 같지만 코드가 더 간결해집니다.

  • messages의 developer 역할 → instructions 로 분리
  • messages → input 으로 변경
  • 답변 꺼내기 : completion.choices[0].message.content → response.output_text (훨씬 간단)

언제 어느 API를 쓸까?

  • ✅ Responses API — 새로 만드는 프로젝트, 웹 검색·파일 검색 등 도구 활용, AI 에이전트 개발
  • ✅ Chat Completions API — 기존 프로젝트 유지보수, 간단한 텍스트 생성

기본 호출

response = client.responses.create(
    model="gpt-6-luna",
    instructions="친절하게 답변하세요.",
    input="파이썬이 뭐야?"
)

response.output_text
